# Security

Altioris is an educational prototype with fictional records. It is not a production student information system and must not be populated with real student or medical data without a separate security and privacy review.

For a suspected vulnerability, use the repository's **Security → Report a vulnerability** option if enabled. Do not post passwords, database files, session cookies or personal records in public issues. If private reporting is unavailable, contact the maintainer through a private channel before sharing exploit details.

Passwords are supplied privately for each installation. The committed repository deliberately contains no working demo passwords. SQLite, credential files and logs belong outside Git. Public deployment requires HTTPS, persistent protected storage and backups; see [deployment notes](docs/deployment.md).
