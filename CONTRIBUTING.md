# Разработка Altioris

Начните с [README](README.md), [визуального контракта](DESIGN.md), [требований](docs/requirements.md) и [архитектуры](docs/architecture.md). Инструкции и промпты опубликованы в [docs](docs/README.md).

1. Создайте ветку от актуального `main` и опишите воспроизводимую проблему или задачу.
2. Для изменения экрана сопоставьте его с соответствующим утверждённым референсом. Сохраняйте реальные DOM-контролы, доступность клавиатуры и адаптивность.
3. Используйте только вымышленные данные. Любой доступ к заявкам, PDF и сообщениям проверяйте по текущему пользователю на сервере.
4. Запустите `npm test`; при изменении референсов — `python scripts/import-references.py`. При изменении интерфейса проверьте 360, 768, 1280 и 1536 px, ошибки и фокус клавиатуры.
5. В PR укажите проблему, итоговое поведение, проведённые проверки и ограничения. Скриншоты должны содержать только демонстрационные данные.

Не добавляйте `runtime/`, `.env`, пароли, cookie, SQLite, локальные профили браузера и журналы. Для расширения поддержки LLM-вызовы и ключи должны оставаться на сервере; модель получает только разрешённый контекст текущего аккаунта.
