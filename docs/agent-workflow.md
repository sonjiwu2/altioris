# Implementation and review workflow

Execute scoped roles sequentially by default. Read the relevant role prompt and approved PNG before changing its screen. Coordinate shared exports, URL parameters and snapshot fields before edits.

1. Verify source status and current reference hashes.
2. Implement the shared design contract and semantic behavior.
3. Run targeted syntax and integration checks.
4. Review actual desktop and mobile renders and interaction results.
5. Record concrete differences and correct observed defects.
6. Commit verified source changes with accurate messages.

Credentials, SQLite, screenshots and temporary scripts stay ignored. Project instructions and approved reference images are published in docs as requested. Keep code, screenshots and test evidence associated with the revision actually inspected. Do not invent independent reviews or claim a hosting deployment from a local server check.
