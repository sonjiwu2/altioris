# Fonts, imagery and project guidance

The application uses original ImageGen artwork, original authored SVG icons and locally served open fonts. See [ASSET_REGISTER.md](ASSET_REGISTER.md).

Font upstreams are https://github.com/googlefonts/great-vibes, https://github.com/googlefonts/marckscript and https://github.com/googlefonts/golos-text. The distributed font binaries originate from https://github.com/google/fonts. Preserve each supplied OFL.txt notice.

The active role guidance is in docs/implementation-guides and the role prompts are in docs/prompts. DESIGN.md is the visual authority. The current reference set consists of 11 PNG files from Altioris_Approved_References.zip. Its hashes are recorded in docs/references/manifest.json.

No third-party scripts or remote fonts run in the application. The historical upstream research inventory is reference metadata; it does not select dependencies or override the current design contract.
