# Руководства разработки

В 30 каталогах `altioris-*` находятся тематические `SKILL.md`: визуальная система, типографика, адаптивность, анимация, HTTP, SQLite, приватность, документы, тестирование и документация.

Начните с [DESIGN.md](../../DESIGN.md), [AGENTS.md](../../AGENTS.md) и [промпта нужного направления](../prompts/README.md). Затем прочитайте соответствующий `SKILL.md`. Эти файлы описывают рабочий процесс и ограничения, а не подключаемые зависимости приложения.

Проверка структуры: `node scripts/install-skills.mjs`. Команда без параметров ничего не скачивает. Дополнительный режим `--upstream` сохраняет закреплённые сторонние материалы и их лицензии в игнорируемом локальном кэше; он не нужен для запуска приложения.
