# Altioris development prompts

These are edited English translations of the available product-development messages, in their original order. Closely related follow-ups are combined where they clarify the same request. This record begins with the earliest product revisions available for review.

## Academic records, documents, and requests

**1. Improve the visual quality of the PDFs.** Please use the supplied document as inspiration for the typography, layout, and overall finish. I want the PDFs to feel deliberately designed. Use the supplied handwritten signature as part of the fictional university stationery where appropriate.

**2. Remove the old test requests that show incorrect dates.** I want to submit a new request myself and test the flow from scratch. Make sure new requests are actually saved in the database.

**3. Use grades from the appropriate session.** Check the assessment dates and use the most recent session with published results when creating a transcript. The grades in the example are from the wrong period. Also remove the decorative image next to “Ask a question about this request.”

## Student support

**4. Build a student assistant that understands everyday questions.** Research what students commonly ask university support teams. Make the assistant recognize different ways of asking the same thing, common keywords, and follow-up questions. Give clear, useful answers about campus services and the student's records. Save the conversation and start with a clean test chat. Add arrows for moving through the conversation and message read indicators, taking inspiration from messaging apps. A well-placed emoji is fine. Think through the main scenarios and test them.

**5. Make the greeting sound natural.** The opening message currently tells me what I should ask. Please make it feel like someone is greeting me and inviting me to talk: “Hello! How can I help you?”

**6. Simplify the assistant's subtitle.** Keep “Automated assistant” and remove the line about it answering from my account data.

**7. Make the assistant more useful outside of the suggested questions.** Look at public university FAQs and student help bots. “Tell me about the dormitory” should answer the housing question or ask what I want to know. It should only give certificate instructions when I ask for a certificate. Give direct, friendly answers to questions about grades. Use the relevant period and avoid dumping a full session's results when I only ask for a quick answer. If a question is unclear or outside the assistant's scope, handle it politely. Give me a few unusual questions to test by hand.

## Desktop layout and interactions

**8. Polish the directory and academic detail panels.** Clear my test chat and give me a list of questions I can try. Make the email copy control smaller. Look at how HSE University presents staff profiles and write the fictional Altioris biographies in a similar professional style, with education and relevant interests where they fit. Fix the empty space around the desktop details for courses, exams, and study-plan selections. Make the details change smoothly when I switch items, and check the buttons and transitions throughout those screens.

## Phone interface and shared data

**9. Improve the Android layout.** Put the hamburger on the left and make it open a smooth, compact navigation drawer. Rework the settings typography and control sizes. Open selected lessons, exams, and similar details in a compact sheet with the same useful information as desktop, including the teacher when one is assigned. Replace the horizontally scrolling teacher list with a more comfortable phone layout. Keep the desktop interface intact.

**10. Fix the drawer and small-screen controls.** Give the department chevron more space from the edge. Show one clear unread count without a stray dot. Make the close button and the phone's Back gesture reliable every time. Keep request dates and status badges readable at small widths. Animate the open and closed eye when showing or hiding the password on both desktop and phone.

**11. Keep the same accounts and records across devices.** The same permanent logins should work on both desktop and phone. Make request status changes and saved support conversations available on both devices for the signed-in account.

**12. Fix the request card where the status overlaps the date.** Keep enough room around “Sent” and the submission date, including at larger text settings.

## Final usability fixes

**13. Make mobile panels close reliably.** A tester could not close a completed request with the X. Fix dismissal even during live updates and check other tabs for similar freezes. Apply the fix to the shared interface so it works for every account.

**14. Trim the assistant's suggested questions and make the answers dependable.** Remove the difficult test scenarios from the visible menu. Keep practical questions with concrete answers based on the fictional university and the student's records. Asking about the QR pass or dark mode should never return the last teacher's details. Keep a simple greeting and give polite feedback when a question makes no sense. Check the remaining questions against the actual responses and show me what each one will return.

**15. Keep the notification count on the same line.** Give the menu row and desktop sidebar enough room for the label and the badge. Do not wrap the badge onto a separate line. Check desktop and phone with the same shared navigation.

**16. Align the desktop faculty list with the profile panel.** Use the available space beside the selected profile and let the list scroll when needed. Keep the phone layout as it is.
