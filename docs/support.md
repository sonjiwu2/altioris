# Помощник Altioris

Чат отвечает по расписанию группы, опубликованным оценкам, сезонному рейтингу, каталогу преподавателей, своим заявкам и уведомлениям. Справочная часть объясняет, где искать пропуск, документы, объявления и настройки.

## Темы из открытых источников

- Справки, выписки, академический отпуск, общежитие и вопросы после пропуска занятий встречаются в справочнике [Студенческого офиса ИТМО](https://student.itmo.ru/ru/student_services_office).
- Расписание, пропуска, рейтинг и публикация результатов входят в разделы [учебного офиса НИУ ВШЭ](https://design.hse.ru/edu/office) и [электронной зачётной книжки НИУ ВШЭ](https://www.hse.ru/studyspravka/zachetbook).
- Учебные документы и стипендии вынесены в отдельные вопросы [факультета МГУ](https://rlcsam.philol.msu.ru/for-students/chavo/). В Altioris суммы стипендий и правила выплат не опубликованы.
- В вопросах про общежитие нужно различать очередь и заселение, стоимость, документы и бытовые правила. Эти темы встречаются в открытых справочниках [ИТМО](https://student.itmo.ru/ru/campus/dorms_and_aparts/booking) и [НИУ ВШЭ](https://www.hse.ru/sho/faq_ru). Действующие правила этих вузов относятся к их собственным общежитиям.
- В примерах [Pounce](https://niss.gsu.edu/digital-library/conditions-under-which-college-students-can-be-responsive-to-nudging/) и [Charlie](https://www.latrobe.edu.au/students/ask-us/chatbot) помощник отвечает по известным темам и объясняет, что делать дальше, если ответа нет. Altioris предлагает конкретное уточнение или доступный раздел. Перевода на оператора в этом чате нет.

## Как формируются ответы

Сервер нормализует русские слова, распознаёт знакомые опечатки, частые сокращения и некоторые слова в неверной раскладке. Он сверяет даты по Москве, ищет дисциплины и преподавателей в каталоге и подставляет актуальные сведения из кабинета. Для коротких уточнений сохраняется тема последнего содержательного ответа и связанные идентификаторы. При нескольких подходящих дисциплинах помощник просит уточнить название. Справочные ответы описывают возможности Altioris. Источники выше использованы для выбора тем.

«Мои оценки» показывает короткую сводку по текущему семестру и предлагает выбрать предмет. Можно явно попросить весь список за конкретную сессию. У общежития Altioris есть вымышленный тариф на двухместную комнату, список документов для заселения и сеть Wi-Fi. Просьба заказать справку ведёт к её форме. Свободные места и очередь чат не показывает.

Помощник использует контекст преподавателя для коротких уточнений о консультации, почте и кабинете. Вопросы о пропуске или теме оформления открывают соответствующие разделы. На непонятный вопрос помощник отвечает вежливо и предлагает уточнить тему.

История и контекст принадлежат текущему аккаунту. Новые сообщение, ответ и контекст сохраняются в одной транзакции SQLite. Интерфейс показывает последние 100 сообщений из истории и отмечает ответ помощника двойной галочкой у исходящего вопроса. Чат работает локально без модели, внешних ключей и сторонних сервисов.

Команда `npm test` проверяет фразы с опечатками, уточнения после перезапуска, учебные даты, доступность оценок и изоляцию заявок между аккаунтами.

## Вопросы для ручной проверки

В кабинете кнопка «Что можно спросить» открывает короткую подборку из 15 вопросов. Выбранный вопрос подставляется в поле ввода и отправляется после нажатия кнопки отправки. Дополнительные сценарии из таблицы проверяются отдельно.

Вопросы в одной строке со стрелкой можно отправить двумя сообщениями подряд.

| Что написать | Что проверить |
| --- | --- |
| «Расскажи про общежитие» → «А сколько стоит?» | Сначала бот уточняет тему, затем называет цену места в двухместной комнате, 1 500 ₽ в месяц. |
| «Не справка нужна, хочу комнату в общаге» | Бот говорит об отсутствии данных о свободных местах и очереди. |
| «В общяге можно заселиться без справки?» | Бот понимает опечатку, перечисляет документы и даёт ссылку на форму справки. |
| «Где заказать справку для общаги?» | Ссылка открывает форму именно этой справки. |
| «А что с вайфаем?» после вопроса про общежитие | Бот называет кампусную сеть, доступ к которой выдают при заселении. |
| «Мои оценки» → «А по сетевому программированию?» | Сначала короткий ответ, затем статус конкретной дисциплины со ссылкой на зачётку. |
| «Сколько зачётных единиц за летнюю сессию 2026?» | Бот отвечает числом по указанной сессии. |
| «А по квантовой кулинарии?» после вопроса об оценках | Бот просит сверить название дисциплины. |
| «Подними мне оценку до десятки» | Бот сообщает, что может показать оценку, и направляет к преподавателю. |
| «Куда некст пара?» | Бот находит ближайшее занятие по расписанию, если оно есть. |
| «Погода завтра будет норм?» | Бот признаёт, что не может ответить. |
| «Можно получить справку об оплате для налоговой?» | Бот сообщает, что документ об оплате недоступен. |
| «Я забыл вернуть книжку, продлите её в библиотеке» | Бот объясняет ограничения выдачи книг и ссылается на объявления библиотеки. |
| «Где посмотреть оценки одногруппника?» | Бот не раскрывает чужие результаты. |
| «Хочу живого человека» | Бот говорит, что специалист сообщения в этот чат не получает. |
