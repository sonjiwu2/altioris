# Approved Altioris University screens

This folder contains exactly the 11 PNGs from Altioris_Approved_References.zip. The source screen size is 1536 x 1024. manifest.json maps filenames and SHA-256 hashes; SHA256SUMS is the plain inventory.

Run python scripts/import-references.py to verify. Run it with the current approved ZIP path to restore the exact approved bytes. Inspect the image matching the route in DESIGN.md before editing. Dynamic data uses the actual account. The settings gear is required in addition to the illustrated navigation.
